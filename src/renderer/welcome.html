第一次使用：配一个 API Key（可选）

晨报机每天早上 07:30 抓一遍你订阅的源，把当天的资讯摆到右上角那张小卡片上。 配一个 API Key 之后，它会再用 AI 从当天几百条里挑出最值得看的 10 条，写成一句话总览。

不配也能用：卡片上照常有当天的资讯，只是不做 AI 精选。 配 Key 这件事随时可以在卡片上的「⚙ 设置」里再做。

三步拿到 Key

  1. 打开下面的申请页面，注册并充几块钱（按每天几百条资讯算，一天大约几分钱）。
  2. 在那里建一个 API Key，复制它。
  3. 粘到下面的框里，点「保存 Key」。
platform.deepseek.com

Key 只留在你这台机器上（默认用系统加密存放），模型调用由这台机器直连供应商、 不经过任何服务器；这个程序里也没有"把 Key 读回来"的通道。
